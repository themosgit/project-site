Detailed Description

High-performance unchained hash table.

Keys/row_ids in contiguous arrays for cache-friendly sequential probe. Bloom filter tags enable early rejection. Hardware CRC32 hash with multiplicative mixing.

Note
Thread-safe build via lock-free partitions.
