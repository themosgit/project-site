Detailed Description

Optimized builder for VARCHAR column pages during materialization.

Uses backward-writing strategy and pre-reserved offset gaps to avoid memmove. Handles long strings (> page capacity) with zero-copy page references. Page layout: [num_rows:u16][num_values:u16][offsets:u16...][GAP][strings...][bitmap].

See also
get_string_view for reading source string data.
plan.h ColumnInserter<std::string> for the base template.
materialize.h materialize_column() for parallel usage.
