Detailed Description

Global thread pool for parallel join and materialization operations.

Provides persistent worker threads (SPC__THREAD_COUNT) to avoid thread creation overhead. Uses generation-based task dispatch with condition variables for synchronization.

See also
execute() for dispatching parallel work.
