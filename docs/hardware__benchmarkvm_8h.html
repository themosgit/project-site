Detailed Description

Hardware configuration for SIGMOD contest benchmark VM.

Intel Xeon E5-2680 v3: 24 threads, 256KB L2/core, 30MB shared L3, AVX2. Activated via SPC__USE_BENCHMARKVM_HARDWARE.

Note
Critical for cache-aware partitioning in UnchainedHashtable::compute_num_partitions().
See also
hardware.h for generic fallback.
hardware_darwin.h for Apple Silicon.
