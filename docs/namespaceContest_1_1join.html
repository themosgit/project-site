Detailed Description

Hash join algorithms: UnchainedHashtable, hash_join(), nested_loop().

visit_rows() iterator, nested_loop_join() for tiny build tables.

JoinInput abstraction, build/probe selection, output column setup.

Hash join build/probe: build_from_columnar(), build_from_intermediate(), probe_intermediate(), probe_columnar().

See also
Contest::platform, Contest::io, Contest::materialize
