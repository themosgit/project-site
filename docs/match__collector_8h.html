Detailed Description

Lock-free parallel match collection for joins.

Collects (build_row_id, probe_row_id) pairs using chunk-chains for O(1) merge.

Thread-local buffers avoid contention; chains linked without copying.

Template parameter Mode enables compile-time specialization for different collection modes, eliminating runtime branching in hot loops.
