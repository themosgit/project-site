Detailed Description

Global arena allocator with per-chunk-type regions.

Provides lock-free per-thread allocation via bump pointers. Single mmap at startup, divided into regions with different page policies. Memory freed only on reset_all() between queries.

See also
worker_pool.h for SPC__THREAD_COUNT.
execute.cpp for reset_all() call pattern.
