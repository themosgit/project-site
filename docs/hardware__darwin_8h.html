Detailed Description

Hardware configuration for Apple Silicon (M1/M2/M3).

128-byte cache lines, 4MB L2/cluster, no L3, NEON SIMD, LSE atomics. Detected via __APPLE__ && __aarch64__.

Note
E-cores have different cache sizes but are not used for joins.
See also
hardware.h for generic x86-64 fallback.
hardware_benchmarkvm.h for contest VM.
