Detailed Description

Intermediate column: 16KB pages of value_t, no header.

All pages are arena-allocated (memory freed on arena reset between queries). write_at() is thread-safe after pages are set up; source_table/column track VARCHAR provenance. Move-only.

See also
construct_intermediate.h, materialize.h
