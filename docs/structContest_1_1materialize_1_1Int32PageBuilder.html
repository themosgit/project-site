Detailed Description

Optimized builder for INT32 column pages during materialization.

Uses amortized overflow checking and efficient bitmap accumulation. Page layout: [num_rows:u16][num_values:u16][values:i32...][bitmap at end].

See also
plan.h ColumnInserter<int32_t> for the base template.
materialize.h materialize_column() for parallel usage.
