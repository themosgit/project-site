Detailed Description

Precomputed 16-bit Bloom filter tags for early probe rejection.

2048 entries (4KB) hopefully will fit in L1. Each tag has exactly 5 bits set. Indexed by (hash >> 32) & 0x7FF (bits 32-42, independent from slot bits).

Tags OR'd into directory during build; probe checks (entry & tag) == tag for early rejection.
