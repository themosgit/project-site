Detailed Description

Hash join build and probe operations.

Supports ColumnarTable and intermediate (column_t) inputs.

Probe uses parallel work-stealing; thread-local match buffers merged after processing.

Probe functions are templated on MatchCollectionMode for zero-overhead mode selection at compile time.
