Detailed Description

Depth-first join tree execution engine.

Traverses plan tree: resolve inputs -> select build/probe -> algorithm selection -> match collection -> output construction.

Flow: execute() -> execute_impl() recursively -> resolve_join_input() for ScanNode (ColumnarTable*) or JoinNode (ExecuteResult). Root produces ColumnarTable; non-root produces ExecuteResult.
