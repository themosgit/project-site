Constructs intermediate results directly from thread-local buffers.

Each thread iterates its own buffer, avoiding the merge step. Total matches computed by summing buffer counts.

Each thread writes its contiguous portion of output pages.

Template Parameters
ModeCollection mode for compile-time specialization.
Parameters
buffersVector of ThreadLocalMatchBuffer from probe.
build_inputBuild side data (ColumnarTable* or ExecuteResult).
probe_inputProbe side data (ColumnarTable* or ExecuteResult).

build_nodePlanNode for build side output_attrs mapping.
probe_nodePlanNode for probe side output_attrs mapping.

resultsPre-initialized ExecuteResult, populated in-place.
